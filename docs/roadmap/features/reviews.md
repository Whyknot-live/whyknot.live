# 09 — Reviews (P2)

Goal: structured, actionable feedback — not star confetti.
Stolen from: Microlaunch (Idea vs Product + Roasts), PH reviews (pros/cons,
helpful votes, AI summary), Trustpilot (verified-purchase model → adapt:
claimed-maker + screened evidence).

## Constraints honored
C2 (self moderation: report flow + human review + public rules), C5.

## Research before build
- [ ] Microlaunch Roasts tone guardrails (blunt but bounded — how?)
- [ ] PH review fields (great/needs-improvement/alternatives)
- [ ] Trustpilot fake-review disclosure stats for our transparency copy

## Build spec
- Two axes: Idea vs Execution (Microlaunch shape), plus Design/Usability
  split for sites (Awwwards echo).
- Helpful votes; maker replies; report → human queue; no anonymous reviews
  (account + email verified, our auth).
- Scores feed profiles; never override editorial score (separate signals).

## Metrics
- Reviews/listing · helpful-vote rate · report rate · median review time.

- [ ] Review content in sitemap (SEO capture like PH `/reviews`)
